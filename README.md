# Mangata & Gallo

A jewelry storefront homepage built with HTML and CSS.

## About the project

This project is a homepage for a fictional jewelry brand specializing in timeless jewelry for engagements, weddings, anniversaries, and other special occasions.

## Built with

- HTML5
- CSS3
- Flexbox
- Responsive design using media queries

## Features

- Brand logo and navigation bar
- Promotional heading and introduction
- Three information cards
- Custom color palette using deep berry, dusty rose, and cream
- Responsive layout for smaller screens
- Hover effect on navigation links

## What I learned

Through this project, I practiced writing semantic HTML, styling elements with CSS, using Flexbox for layout, adding hover effects, and adapting a webpage to different screen sizes.
